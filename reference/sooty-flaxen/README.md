## Kernregeln (aus den Folien)

**Beide Gene (Sooty = STY, Flaxen = F) sind rezessiv und ungetestet:**
- Nur homozygot (STYSTY / FF) sichtbar. Heterozygote Träger (STYn / Fn)
  sehen normal aus, können aber Nachkommen mit dem Merkmal haben.
- Sooty ist bei Fohlen **nicht** erkennbar (Sooty-/Nicht-Sooty-Fohlen
  sehen gleich aus). Flaxen **ist** bei Fohlen bereits sichtbar.
- Sooty auf Bay/Buckskin-Basis ist ein anderer visueller Effekt als Sooty
  auf Chestnut/Palomino-Basis (dort verursacht es Liver Chestnut /
  Chocolate Palomino).
- Zeigt sich **nicht** auf Grey, Black, Bay (Sooty) bzw. wird von Cream
  überdeckt (Flaxen).

**Trägerschaft ableiten:**
1. Elternteil zeigt das Merkmal sichtbar → Fohlen ist 100% Träger.
2. Ein Nachkomme zeigt das Merkmal → beide Elternteile sind mind. Träger.
3. Sonst nur durch testweise Verpaarung feststellbar.

**Zucht-Wahrscheinlichkeiten (Punnett-Square):**
- Träger × homozygot → 50% Nachkommen homozygot (sichtbar)
- Träger × Träger → 25% Nachkommen homozygot
- homozygot × Nicht-Träger → 100% Träger (unsichtbar), erst 2 Generationen
  später wieder sichtbar möglich
